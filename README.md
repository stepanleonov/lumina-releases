# Lumina — пять в ряд

Здесь публикуются установщики игры **Lumina** для Windows. Исходный код живёт в отдельном репозитории.

## Скачать

Последняя версия — в разделе **Releases** справа: `Lumina-Setup-<версия>.exe`.

- Запустите установщик, примите лицензию, выберите папку, оставьте галочку «Ярлык на рабочем столе».
- Windows может показать «Защитник Windows предотвратил запуск» (программа не подписана): нажмите «Подробнее» → «Выполнить в любом случае».
- Обновление поверх старой версии сохраняет рекорды и настройки (они лежат в `%APPDATA%\Lumina`).
- Игра сама проверяет здесь новые версии и предлагает обновиться прямо из меню.
